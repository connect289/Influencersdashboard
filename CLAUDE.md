# Repository map

This repository holds several separate Eduwit products that share one production Supabase project
(`xlseqwgyjuqhktrguhyc`, live — read-only unless a product's own docs and the owner say otherwise):

- `b2b-crm/` — B2B partner CRM (crm.eduwit.in). Docs in `docs/`.
- `b2c-crm/` — Eduwit Spark, the B2C CRM (spark.eduwit.in). Docs in `b2c-crm/docs/`.
- `website/` — the new public website eduwit.in. **Read `website/CLAUDE.md` first; to resume the build, read
  `website/docs/PROGRESS.md`.**

Never change one product's code while working on another.
