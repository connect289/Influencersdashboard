criteria in `docs/PHASES.md`, this file is the resumable state of the build: a new session resumes from here, not from
chat history.

Precedence used throughout (specification §1): the System Map describes, the prerequisites doc wins on access,
credentials, test identities, thresholds, recipients and its §5–7 decisions, the specification decides everything else.
Where that does not settle a contradiction, both readings are recorded here and the safer one (writes less, alerts more)
is taken.
