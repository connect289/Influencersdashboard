# Font licences

- `inter-opsz-latin.woff2` — Inter (Rasmus Andersson), SIL Open Font License 1.1. Latin subset of the variable font
  (opsz 14–32, wght 100–900) as served by Google Fonts.
- `bricolage-opsz-latin.woff2` — Bricolage Grotesque (Mathieu Triay), SIL Open Font License 1.1. Latin subset of the
  variable font (opsz 12–96, wght 200–800) as served by Google Fonts.

Only the Latin subset is self-hosted so that characters outside it (for example the rupee sign ₹, U+20B9) fall back to
the system font instead of downloading a second ~130 KB file. Licence text: https://openfontlicense.org
